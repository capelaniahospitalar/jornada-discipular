## Como publicar no GitHub Pages

### 1. Faça upload dos arquivos
No repositório, clique em **"uploading an existing file"** e envie:
- `index.html`
- `manifest.json`
- `service-worker.js`
- `icon-192.png`
- `icon-512.png`
- `README.md`

### 2. Ative o GitHub Pages
1. Vá em **Settings** (aba do repositório)
2. No menu lateral, clique em **Pages**
3. Em **Source**, selecione **Deploy from a branch**
4. Em **Branch**, selecione **main** e pasta **/ (root)**
5. Clique em **Save**

### 3. Aguarde ~2 minutos
O link estará ativo em:
```
https://capelaniahospitalar.github.io/jornada-discipular/
```

## Como compartilhar via WhatsApp
Basta enviar o link acima. O usuário:
1. Abre o link no navegador
2. Toca em **"Adicionar à tela inicial"** (Android) ou **"Compartilhar → Adicionar à tela de início"** (iPhone)
3. O app aparece na tela inicial com o ícone do Hospital Adventista Silvestre

## Funciona offline?

⚠️ A IA de Apoio ao Discípulo requer conexão ativa.
